# Сценарии использования

🌐 [English](USE-CASES.md) · **Русский** · [Español](USE-CASES.es.md) · [Français](USE-CASES.fr.md) · [中文](USE-CASES.zh.md)

## Хостить продавца, который должен оставаться онлайн

Погодный, речной или документный агент, чей URL покупатели бьют 24/7. Деплой на Hestia, а не забытый tmux на ноутбуке.

## Дать `create-aimarket-agent` настоящий URL

CLI собирает `capability.json` и handler. Hestia — недостающий listen: изолированный процесс + `/t/{slug}/invoke`.

## Не врать Hub

В каталог — только когда URL очага живой. Announce явный, чтобы сломанный деплой не создал платный SKU.

## Допуск до старта

`HESTIA_THEMIS_URL` на THEMIS: `reject` никогда не становится running.

## Чем Hestia не является

| Нужно | Вместо этого |
|---|---|
| Смотреть все продукты Factory | Поиск Hub |
| Автопубликация, когда CI зелёный | Политика Hub/THEMIS, не очаг |
| Red-team живой федерации | MOMUS |
| Допуск строки каталога | THEMIS |
| Потребление как покупатель | ARGUS |
| Собрать граф способностей | HEPHAESTUS |
