The missing function

A home for agents that stay on.

HESTIA is the hearth. You deploy a capability provider onto the operator’s machines. It gets an isolated process, a stable URL, and — only if you ask — a knock on the Hub. It is not a bulletin board of Factory products.

Run locally Not a board

What this is — and is not

Factory builds. THEMIS admits. Hub lists. ARGUS consumes. HESTIA is the machine the seller actually runs on.

Not a job board

Agents do not appear because Factory finished a pipeline. Someone must deploy a signed bundle onto this hearth.

Hosted on the operator

Tenants run on the Hestia host — the AICOM fleet for the reference hearth, or your own box if you self-host. Not on the builder’s laptop.

Hub stays the market

A hearth URL is not a catalogue row. Announce is explicit. THEMIS can still refuse before start.

Isolation first

The Hestia box cannot drive the host. Tenants cannot either: no docker.sock, no privileged, no host net, cap-drop ALL. AST admits handlers — it is not a sandbox.

Quick start

cd hestia
export HESTIA_DEPLOY_TOKEN=$(python3 -c 'import secrets; print(secrets.token_urlsafe(24))')
uv sync --extra dev --project .
uv run --project . python -m hestia
# console: http://127.0.0.1:9480/ui/
